# COVID-19 Trends & Mortality Analysis (United States)

## Overview
This project analyzes COVID-19 case trends and death rates across U.S. states using data from the Johns Hopkins University COVID-19 repository. The goal is to explore spatial and temporal patterns in the pandemic using interactive and statistical visualizations.

---

## Dataset
- Source: Johns Hopkins University CSSE COVID-19 Data Repository
- State-level confirmed cases and deaths
- Time-series cumulative data

---

## Objectives
- Analyze state-wise case and death distribution
- Identify high-risk states
- Visualize geographic patterns using choropleth maps
- Explore cumulative trends using interactive time-series plots
- Compare state-level mortality spread

---

## Key Visualizations

- Choropleth Map (Total Cases by State)
- Bubble Map (Total Deaths by State)
- Histogram (Distribution of Total Cases)
- Boxplot (Death spread across states)
- Interactive Time-Series Plot

---

## Key Insights

- California, Texas, and Florida recorded the highest case counts.
- Mortality rates varied significantly across states.
- Early 2020 showed exponential growth in cumulative cases.
- Spatial visualization highlights uneven distribution of cases and deaths.

---

## Technologies Used

- Python
- Pandas
- Plotly
- Folium

## How to Run

1. Install dependencies:
   ```
   pip install pandas plotly folium seaborn matplotlib
   ```

2. Open:
   ```
   covid19_analysis.ipynb
   ```

3. Run all cells to generate maps and charts.
